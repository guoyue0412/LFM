已完成工作（二）

代理模型：DNN → MoE 演进 已完成

对应开题任务 T2：DNN 气动代理模型构建 → 实际升级为 MoE 架构

V1 实现：单 MLP DNN

输入 47 维 (3 工况 + 22×chord + 22×twist)
隐藏层 [64, 128, 64] · ReLU · Dropout 0.001
输出：Fx, Fy, Fz, Torque
MSE 损失 · Adam · CosineAnnealingLR · 5000 epochs
100 几何 × 72 工况 = 7200 样本 (train:test = 9:1)
Fx MAPE 1.03% · Fz 1.50% · Torque 0.99%

问题：分布内精度高 ≠ 外推可靠

CMA-ES 无约束优化 → FM=1.004（物理不可能）
证据：twist 100% 截面 OOD, chord 68% 截面 OOD
RPM 外推 +1455（超出 [4000,6500] 范围）
PPO 同样受影响：FM=0.899 但 OOD 仍不可控
→ 核心问题不在优化算法，而在代理模型缺乏可信度感知

实际方案：MoE 代理模型 (V2)

Shared Encoder 47→64 (BatchNorm + ReLU)
Gating Network 64→K (softmax 权重)
K=4 Experts 各 64→128→8 [μ₄ + log_σ₄]
输出：[T, H, My, Q] + [σT, σH, σMy, σQ]

相比 DNN 的核心改进：

  • + 异方差 NLL 损失 → 自动学习预测不确定度
  • + My 直接预测（不再解析估算）
  • + 混合方差 σ² = Σπk(σk² + μk²) − μ²
  • + Balance + 熵正则化防 expert 坍缩
  • + 输入维度 11→47（含 22 截面分布）

为什么选 MoE 而非 MC-Dropout / Ensemble？

① 单次前向同时获得 μ+σ，CMA-ES 每代评估 16×200 次，推理成本敏感
② Gating 天然适配多工况分区 (低/高 RPM, 小/大攻角)
③ 异方差 NLL 学出输入相关的 σ（非固定 dropout 率）
④ σ 直接进目标函数：J += λU·σ (λU=50) → 惩罚高不确定区域
⑤ σ > 0.1 (归一化) 触发主动补点 → LLFVW 补采 → 增量微调

OOD 外推陷阱（核心发现）

现象：CMA-ES V1 给出 FM=1.004（物理不可能值）
诊断：twist 22/22 截面 OOD, chord 15/22 截面 OOD, RPM 超出 +1455
根因：MLP 在训练分布内 MAPE 1%，但对 OOD 输入外推不可靠
对比：PPO 也产出 FM=0.899（OOD 不可控），证明问题不在优化算法
→ 驱动方法演变：需要代理模型具备不确定度感知能力

V4 边界解 → 数据扩展

现象：8 个 CP 全部卡在约束边界 (chord 交替上/下限, twist 全在下限)
解释：100 几何的 ±5% 边距可信域太窄，全局最优在域外
方案：100→1000 几何 (±30% LHS)，扩大可信域后重新优化

配平约束求解器（开题方案无此模块）

三轴平衡：Fx=0, Fz=mg, My=0
求解变量：[α, Ω₁, Ω₂] (迎角+前后桨转速)
范围：RPM∈[4000,6500] · α∈[2°,8°]

V1 问题收敛率仅 ~3% (scipy.root 对初值敏感)
V2 改进多初始值×6 + 热启动 → 100% 收敛
V2 新增My 由 MoE 直接预测 (非解析 km·T·R·μ)
V2 优化预分配缓冲 (2,47) + last 字典热启动

复合目标函数

J = Pelec/V + λR·‖R‖² + λU·σ + λG·Cgeo
配平失败 → J = 10⁶ 大惩罚淘汰

总结

研究创新点与预期成果

1

MoE 代理模型 + 不确定度量化

相对现有工作：Wu et al. (2024), Mian et al. (2021) 等螺旋桨代理模型均使用单 MLP/Kriging，无预测可信度输出
本文新增：K=4 混合专家 + 异方差 NLL → 伴随输出 σ； 混合方差 σ²=Σπk(σk²+μk²)−μ² 量化认知不确定性
证据：V1 MLP 在 OOD 区域给出 FM=1.004 虚假预测，σ 感知可防止此类失效

2

前飞差速配平嵌套优化

相对现有工作：Klimczyk (2022), Oliveira et al. (2024) 等仅优化悬停工况，不涉及前飞配平约束
本文新增：在 CMA-ES 每次评估中嵌套三轴配平求解 [α,Ω₁,Ω₂]； My 由 MoE 直接预测（非解析估算 km·T·R·μ）
证据：多初始值×6 → 100% 收敛率，确保优化结果物理可实现

3

OOD 感知 + 主动补点闭环

相对现有工作：代理模型优化文献 (Tao 2019, Bu 2022) 普遍假设模型在全域可靠
本文新增：实证揭示 OOD 陷阱 (84% 截面外推) → 数据驱动硬约束 (±5% 边距) + σ 引导主动补点
闭环：优化→σ超阈值→识别盲区→补采LLFVW数据→重训→再优化
